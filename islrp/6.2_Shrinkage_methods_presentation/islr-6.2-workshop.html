Ridge and the lasso both minimize the residual sum of squares plus a penalty on the coefficients:

\[\text{Ridge: } \text{RSS} + \lambda \sum_{j} \beta_j^2 \qquad\qquad \text{Lasso: } \text{RSS} + \lambda \sum_{j} |\beta_j|\]

In R, glmnet fits both. alpha = 0 gives ridge and alpha = 1 gives the lasso. It standardizes the predictors before fitting.

1. Wheat Yield from Genetic Markers

These data come from the wheat breeding program at the International Maize and Wheat Improvement Center, which tests wheat lines in trials around the world.

  • Rows: 599 wheat lines (varieties).
  • Features: 1,279 genetic markers, scored 0 or 1 to record whether a particular stretch of DNA is absent or present.
  • Response: grain yield shown as an index: 100 is the average line, and 10 points is one standard deviation.

We train on 80% of the lines (479) and test on the other 20% (120).

PREDICT: Yield is thought to be shaped by many genes, each with a small effect. Which method will predict yield best on the test lines: least squares, ridge, or the lasso? Why?

library(glmnet)
data(wheat, package = "BGLR")   # loads wheat.X (markers) and wheat.Y (yield)
X <- wheat.X
y <- 100 + 10 * wheat.Y[, 1]    # yield index: 100 = average line, 10 = one SD

set.seed(853)
train <- sample(nrow(X), 479)   # 80% to train; the other 120 lines are for testing
test  <- setdiff(seq_len(nrow(X)), train)

rmse <- function(pred, actual) sqrt(mean((actual - pred)^2))

# Least squares on the chosen marker columns; returns one row of the results table
ls_row <- function(columns) {
  fit   <- lm(y[train] ~ X[train, columns])
  coefs <- coef(fit)
  used  <- sum(!is.na(coefs)) - 1   # markers lm could estimate (not counting the intercept)
  coefs[is.na(coefs)] <- 0          # lm returns NA for markers it can't estimate
  data.frame(method         = "Least squares",
             markers_chosen = length(columns),
             markers_used   = used,
             train_rmse     = sqrt(mean(resid(fit)^2)),
             test_rmse      = rmse(cbind(1, X[test, columns]) %*% coefs, y[test]))
}

# Ridge or the lasso; returns one row of the results table
shrink_row <- function(fit, name) {
  data.frame(method         = name,
             markers_chosen = ncol(X),
             markers_used   = sum(coef(fit)[-1] != 0),
             train_rmse     = rmse(predict(fit, X[train, ]), y[train]),
             test_rmse      = rmse(predict(fit, X[test, ]), y[test]))
}

# Print ordinary numbers rounded, and huge ones in scientific notation
show_table <- function(results) {
  show_rmse <- function(x) ifelse(x > 1000, format(x, scientific = TRUE, digits = 2), round(x, 2))
  results$train_rmse <- show_rmse(results$train_rmse)
  results$test_rmse  <- show_rmse(results$test_rmse)
  results
}

# Ridge and the lasso use all 1,279 markers, each with its own fixed lambda
# (the lambda values were chosen by cross-validation; Section 3 shows why the choice matters)
ridge <- glmnet(X[train, ], y[train], alpha = 0, lambda = 34)
lasso <- glmnet(X[train, ], y[train], alpha = 1, lambda = 0.48)
shrink_rows <- rbind(shrink_row(ridge, "Ridge"), shrink_row(lasso, "Lasso"))

# Least squares gets all the markers, sorted by their individual R-squared with yield
r2     <- cor(X[train, ], y[train])^2
ranked <- order(r2, decreasing = TRUE)

show_table(rbind(ls_row(ranked), shrink_rows))
         method markers_chosen markers_used train_rmse test_rmse
1 Least squares           1279          478       0.00    119.16
2         Ridge           1279         1279       6.58      8.15
3         Lasso           1279           94       7.15      8.58

NoteThe point

When many features each have a small effect, ridge predicts best: it keeps every marker and shrinks them all. Least squares on all the markers fits the training lines perfectly and predicts new lines badly. Using only the top-ranked markers stops the blow-up, but it doesn’t catch ridge.

2. Yield of a Chemical Manufacturing Process

These data come from a 27-step process that makes a pharmaceutical product.

  • Rows: 176 samples of the process.
  • Features: 57 measurements: 12 of the biological starting material, and 45 of the manufacturing process, such as temperature, drying time, and washing time.
  • Response: percent yield of the final product.

We train on 80% of the samples (141) and test on the other 20% (35).

PREDICT: Suppose only a few of these 57 measurements really drive yield. Which method will predict yield best on the test samples: least squares, ridge, or the lasso? Why?

3. Finding the Best λ

Back to the wheat data from Section 1: the same 599 lines, 1,279 genetic markers, and yield index. This time we fit ridge at 200 values of \(\lambda\) and average the test error at each one over 10 random 80/20 splits.

PREDICT: As \(\lambda\) grows from almost zero to very large, what shape will the test error follow?

library(glmnet)
library(ggplot2)
data(wheat, package = "BGLR")   # loads wheat.X (markers) and wheat.Y (yield)
X <- wheat.X
y <- 100 + 10 * wheat.Y[, 1]    # yield index: 100 = average line, 10 = one SD

# Plot average test RMSE across lambda for one method: alpha = 0 is ridge, alpha = 1 is the lasso
plot_lambda_curve <- function(alpha) {
  lambdas <- 10^seq(5, -3, length.out = 200)   # 200 values, from very large to very small

  # Test RMSE at each lambda, for one random 80/20 split
  split_rmse <- function(seed) {
    set.seed(seed)
    train <- sample(nrow(X), 479)   # 80% to train; the other 120 lines are for testing
    test  <- setdiff(seq_len(nrow(X)), train)
    fit   <- glmnet(X[train, ], y[train], alpha = alpha, lambda = lambdas)
    preds <- predict(fit, X[test, ], s = lambdas)
    sqrt(colMeans((preds - y[test])^2))
  }

  # Average over 10 random splits, and find the lambda where the average is lowest
  errors <- data.frame(lambda = lambdas, test_rmse = rowMeans(sapply(1:10, split_rmse)))
  best   <- errors[which.min(errors$test_rmse), ]

  ggplot(errors, aes(lambda, test_rmse)) +
    geom_line(linewidth = 0.8, color = "steelblue") +
    geom_point(data = best, size = 3, color = "steelblue") +
    geom_text(data = best, vjust = 2,
              aes(label = sprintf("Minimum: lambda = %.3g, test RMSE = %.2f", lambda, test_rmse))) +
    scale_x_log10(breaks = 10^(-3:5),
                  labels = format(10^(-3:5), scientific = FALSE, drop0trailing = TRUE,
                                  trim = TRUE, big.mark = ",")) +
    scale_y_continuous(breaks = pretty(c(best$test_rmse - 0.6, errors$test_rmse), n = 12)) +
    expand_limits(y = best$test_rmse - 0.6) +
    theme_minimal() +
    labs(title = if (alpha == 0) "Ridge" else if (alpha == 1) "Lasso" else paste0("Elastic-Net (alpha = ", alpha, ")"),
         x = "lambda (log scale)", y = "Average test RMSE (yield points)")
}

plot_lambda_curve(alpha = 0)   # ridge is alpha = 0, lasso is alpha = 1

YOUR TURN: Change alpha to the value for the lasso and run this chunk. How does the best \(\lambda\) compare with ridge’s?

# ridge is alpha = 0, lasso is alpha = 1
plot_lambda_curve(alpha = 0)   # <- change me to lasso regularization
NoteThe point

Test error falls and then rises as \(\lambda\) grows. Too little shrinkage leaves high variance, too much adds bias, and the best \(\lambda\) is in between. The best value is very different for ridge and the lasso, so it has to be chosen separately for each method, which is what cross-validation does.

## 3. Finding the Best λ

Back to the wheat data from Section 1: the same 599 lines, 1,279 genetic
markers, and yield index. This time we fit ridge at 200 values of
$\lambda$ and average the test error at each one over 10 random 80/20
splits.

> **PREDICT:** As $\lambda$ grows from almost zero to very large, what
> shape will the test error follow?

```{r}
library(glmnet)
library(ggplot2)
data(wheat, package = "BGLR")   # loads wheat.X (markers) and wheat.Y (yield)
X <- wheat.X
y <- 100 + 10 * wheat.Y[, 1]    # yield index: 100 = average line, 10 = one SD

# Plot average test RMSE across lambda for one method: alpha = 0 is ridge, alpha = 1 is the lasso
plot_lambda_curve <- function(alpha) {
  lambdas <- 10^seq(5, -3, length.out = 200)   # 200 values, from very large to very small

  # Test RMSE at each lambda, for one random 80/20 split
  split_rmse <- function(seed) {
    set.seed(seed)
    train <- sample(nrow(X), 479)   # 80% to train; the other 120 lines are for testing
    test  <- setdiff(seq_len(nrow(X)), train)
    fit   <- glmnet(X[train, ], y[train], alpha = alpha, lambda = lambdas)
    preds <- predict(fit, X[test, ], s = lambdas)
    sqrt(colMeans((preds - y[test])^2))
  }

  # Average over 10 random splits, and find the lambda where the average is lowest
  errors <- data.frame(lambda = lambdas, test_rmse = rowMeans(sapply(1:10, split_rmse)))
  best   <- errors[which.min(errors$test_rmse), ]

  ggplot(errors, aes(lambda, test_rmse)) +
    geom_line(linewidth = 0.8, color = "steelblue") +
    geom_point(data = best, size = 3, color = "steelblue") +
    geom_text(data = best, vjust = 2,
              aes(label = sprintf("Minimum: lambda = %.3g, test RMSE = %.2f", lambda, test_rmse))) +
    scale_x_log10(breaks = 10^(-3:5),
                  labels = format(10^(-3:5), scientific = FALSE, drop0trailing = TRUE,
                                  trim = TRUE, big.mark = ",")) +
    scale_y_continuous(breaks = pretty(c(best$test_rmse - 0.6, errors$test_rmse), n = 12)) +
    expand_limits(y = best$test_rmse - 0.6) +
    theme_minimal() +
    labs(title = if (alpha == 0) "Ridge" else if (alpha == 1) "Lasso" else paste0("Elastic-Net (alpha = ", alpha, ")"),
         x = "lambda (log scale)", y = "Average test RMSE (yield points)")
}

plot_lambda_curve(alpha = 0)   # ridge is alpha = 0, lasso is alpha = 1
```

Test error falls and then rises as $\lambda$ grows. Too little shrinkage
leaves high variance, too much adds bias, and the best $\lambda$ is in
between. The best value is very different for ridge and the lasso, so it
has to be chosen separately for each method, which is what
cross-validation does.
:::
